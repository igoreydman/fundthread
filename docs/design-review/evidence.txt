PROJECT EVIDENCE — FundThread, observed November 8, 2026.
The application is React/TypeScript in a Tauri desktop shell. The supplied captures are the real browser preview at 1480x1000 or 390x844, with fictional Tidepath Family Alliance records. Browser data is explicitly labeled synthetic, remains in memory and resets on reload. Desktop storage uses SQLCipher and starts empty. The Mac is currently locked, so native UI operation has not been performed.
Observed browser workflow: imported sample originals render beside a receipt queue and a three-tab Details/Funding/Decision review. Embedded-text extraction produces individual source-linked candidate buttons. Existing merchant and context fields remain unchanged until an explicit candidate selection or manual edit. A scanned synthetic PDF with no text layer was read using bundled Tesseract English assets. No external HTTP request was observed during that scan workflow.
Observed browser workflow: editing purpose then navigating opens a save/discard/keep-editing dialog. Saving a draft preserves the new purpose when returning. Mark reviewed creates a new revision. External approver and evidence-reference entries are then required to record a decision. A partial payment is recorded in a separate dialog. Report preview includes partially-paid status and omits claimant and approver names for the Funder profile.
Observed browser workflow: privacy review shows the original with separately saved black-mask regions. Pattern/name suggestions can be selected; manual drag regions are also available. Selecting a suggestion now scrolls its source region into view. A fresh export requires pages to have been opened and a new human review checkbox. The saved PDF was inspected structurally for no font entries or embedded file names, and decompressed page-image pixels inside the selected mask were black. Reopening privacy review retains the mask but does not retain the review checkbox.
Observed browser workflow: a fund can be created with a code, budget, dates, category rules and notes. Backup controls are disabled in browser preview, with desktop-only explanatory text. Compact layout has no horizontal page overflow and preserves a purpose edit after dismissing the navigation guard using Escape.
